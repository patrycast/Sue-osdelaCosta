# Sueños de la Costa — sitio web

Stack: React 18 + Vite, styled-components, react-router-dom v6.

    npm install
    npm run dev      # desarrollo
    npm run build    # producción (carpeta dist/)

Editá `src/data.js` para cambiar teléfono/WhatsApp, horarios, productos y reseñas.
Para deploy en Netlify/Vercel agregá una regla de reescritura a `index.html` (SPA).
